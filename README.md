# plateia

A chat room and dashboard for running software projects with AI agents.

*Plateia* (πλατεία) is the town square: the one place where everyone working
on a set of projects meets. Here that means:

- **chat:** every project's channels on a local IRC server, live, with the
  owner's mentions up front;
- **projects:** each project's manager, the work in flight, and the questions
  waiting on the owner;
- **health:** the services behind it all, and any message that wasn't
  delivered.

It runs on the owner's own machine and is reached only over a private
[Tailscale](https://tailscale.com) network, never the open internet.
